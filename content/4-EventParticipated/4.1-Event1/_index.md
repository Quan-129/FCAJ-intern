# Summary Report: "Tech Sharing Seminar - Cloud, DevOps & AI/ML Applications"

### Event Objectives

- Connect and learn from experts in System/DevOps, Cyber Security, and AI.
- Gain insights into real-world career paths from IT Helpdesk to System Admin.
- Explore modern solutions for cloud infrastructure, security, and backend architecture.
- Understand the integration of Artificial Intelligence in cybersecurity and application development.

### Speakers

- **Tran Trung Vinh** – Expert in System Admin & DevOps Roadmap.
- **Dai** – Cyber Security Specialist.
- *(Other technical leads and engineers from the industry)*

### Key Highlights

#### 1. System Admin & DevOps Roadmap
- **Career trajectory:** Analyzed the path from IT Helpdesk to System Admin and beyond.
- **Incident management:** Real-world case studies on resolving critical system outages (e.g., total downtime caused by disk I/O overload).
- **Infrastructure migration:** Best practices for cloud migration and system optimization using **Containerization (Docker)** to ensure consistency across environments.

#### 2. Machine Learning in Cyber Security
- **WAF Limitations:** Analyzed why traditional ruleset-based Web Application Firewalls often suffer from blind spots.
- **ML-driven Security:** Proposed an advanced system using **LightGBM** (Machine Learning algorithm) to collect and preprocess logs for high-accuracy detection of threats like SQL Injection and XSS.

#### 3. Game Architecture & RAG Systems
- **Backend Infrastructure:** Deep dive into building a robust backend using **AWS (API Gateway, Lambda, DynamoDB)**.
- **Network Protocols:** In-depth evaluation and comparison between **HTTP Polling, WebSockets, and UDP** for real-time game state synchronization.
- **RAG Implementation:** Introduction to **Retrieval-Augmented Generation (RAG)** techniques for automated document analysis and intelligent information retrieval.

### Key Takeaways

#### Technical Mindset
- **Troubleshooting Approach:** Learned the senior-level methodology for incident isolation: starting from hardware metrics (CPU, RAM, Disk I/O) down to granular Application Logs.
- **Protocol Selection:** Understanding the trade-offs between protocols is essential for designing real-time, high-performance systems.

#### Architectural Design
- **Serverless Efficiency:** Utilizing AWS Lambda and DynamoDB allows for highly scalable backends without the overhead of server management.
- **AI Integration:** Modernizing security through ML is a proactive approach compared to traditional static rule-based systems.

#### Career Development
- **Bridging the Gap:** Transitioning from basic IT operations to advanced DevOps requires a strong foundation in containerization and cloud-native architecture.
- **Information Synthesis:** Practicing the ability to extract core technical values from complex presentations is a vital skill for academic and professional growth.

### Applying to Work

- **Backend Optimization:** Apply knowledge of AWS services (API Gateway, Lambda, DynamoDB) to refine the backend architecture of the **Antygravity** application.
- **Agent Communication:** Optimize the routing mechanism between the client and AI Agents based on the protocol comparisons learned.
- **Coding Standards:** Apply the security design mindset from the WAF session to ensure robust input data validation and maintain **Clean Code** principles.
- **Demo Readiness:** Use the speaker's presentation style and technical clarity as a benchmark for upcoming university software demonstrations and final reports.

### Event Experience

Attending the **"Tech Sharing Seminar"** was a significant milestone in my professional development, providing a bridge between academic theory and industry-grade application.

#### Learning from industry veterans
- Practical sharing on career progression and incident handling provided a clear roadmap for my own growth as a Computer Science student.
- Analyzing real-world outages reinforced the importance of proactive system monitoring.

#### Technical exposure
- Deepened my understanding of the **containerization** workflow (Docker) and how it solves deployment environment inconsistencies.
- Grasped the end-to-end process of deploying AI models, from **data collection to deployment**, which is highly relevant to my interest in predictive algorithms.

#### Lessons learned
- **Proactive Security:** Moving from static WAF rules to **ML-based threat detection** is the future of resilient security.
- **Scalability by Design:** Adopting serverless patterns and proper network protocols (WebSockets/UDP) is key to building systems that handle high concurrent user traffic.
- **Mindset over Tools:** While AWS tools are powerful, the ability to isolate and resolve system incidents through logical debugging remains the most critical skill for any engineer.
